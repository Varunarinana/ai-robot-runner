AI ROBOT RUNNER 3D — GitHub Pages + PWABuilder

1. Create a PUBLIC GitHub repository named ai-robot-runner.
2. Upload every file/folder in this ZIP to the repository root. index.html must be at root.
3. Open repository Settings > Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for deployment. Your URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/ai-robot-runner/

Then:
1. Open https://www.pwabuilder.com/
2. Enter that HTTPS URL and analyze.
3. Choose Package for stores > Android > Google Play.
4. For a first app choose a new signing key.
5. Download the package. Keep signing key and passwords safe.

GitHub Pages content is public. Do not upload secrets. Test before publishing. Play Store approval is not guaranteed; Play Console testing and declarations still apply.
